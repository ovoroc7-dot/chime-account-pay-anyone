# Chime Replica UI

Build an authentic replica of the Chime mobile app home and checking account UI flow based on the attached video recording. Include the Home dashboard with account balances (Checking $30.29, Credit Builder setup, SpotMe preview), promotional banners, and financial tools navigation, as well as the transition into the Checking Account detail screen with routing/account info, action pills (Transfer, Cards, etc.), search, and date-grouped transaction history (e.g. One Finance, Qube Money) with interactive transaction details.
